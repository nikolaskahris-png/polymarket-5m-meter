# ADDENDUM 1 στο PREREG_phase3 (17/11/2026, πριν ξεκινήσει η καταγραφή)

Αλλαγή υποδομής, όχι μεθόδου: η καταγραφή ΔΕΝ γίνεται σε GitHub Actions. Οι όροι του GitHub απαγορεύουν στους hosted runners δραστηριότητα άσχετη με παραγωγή/δοκιμή/deployment/δημοσίευση του software project· μια συνεχής σύνδεση 14 ημερών είναι τέτοια χρήση και θα ρίσκαρε τον λογαριασμό.
Αντί για αυτό (αντικαθιστά τις γραμμές «Αρχεία ως Actions artifacts» και «Αλυσίδα jobs» του §1):
- Ένας VPS (Hetzner, Ubuntu 24.04) τρέχει συνεχώς το `phase3/recorder.py` ως systemd service (Restart=always). Μία διεργασία, άρα όχι διπλά γεγονότα· κάθε επανασύνδεση γράφεται ως γραμμή G (κενό).
- Τα δεδομένα μένουν στον δίσκο του VPS (/data/rec). Στο GitHub (branch `vps-data`) πάει μόνο κατάσταση κάθε 30' και αποτελέσματα εργασιών < 20 MB.
- Η προσομοίωση (§2–3) τρέχει στον ίδιο VPS, ως εργασία από το `phase3/vps/jobs/`, με κώδικα που κλειδώνεται με sha256 πριν τρέξει.
- Ο πιλότος της 1ης ώρας (> 3 GB/μέρα → 5 επίπεδα) μετριέται από το `status/disk.txt`.
Όλα τα υπόλοιπα του PREREG_phase3 μένουν ως έχουν.
